# App Store asset specs (as encoded in `farm/lib/apple.ts`)

## App icon
1024×1024 PNG, **no alpha**, no rounded corners (iOS masks), sRGB/P3. Source: `store/icon.svg` → `store/icon-1024.png`
+ `app/assets/images/icon.png`.

## Screenshots (PNG/JPEG, no alpha, 1–10 per device size)
| Slot | ASC display type | Accepted sizes (portrait) | Generated |
|---|---|---|---|
| iPhone 6.9" (required) | `APP_IPHONE_67` | 1320×2868, 1290×2796, 1260×2736 | 1320×2868 |
| iPad 13" (only if `supportsTablet`) | `APP_IPAD_PRO_3GEN_129` | 2064×2752, 2048×2732 | 2064×2752 |
Smaller sizes are scaled from these by App Store Connect.

Raw captures: web build at 440×(956−62−34)pt @3× with a drawn status bar/home indicator, or native simulator
captures (`store/raw/native/*.png`, preferred). Framed with caption by `farm assets`.

## App preview video (optional, up to 3 per size)
iPhone 6.9"/6.5": **886×1920** portrait, 15–30 s, ≤30 fps, H.264 (or ProRes 422 HQ), .mp4/.mov, ≤500 MB, with an audio
track (silent AAC is fine). Must be captured from the app (no device frames, no people using the device).
Generated by recording the app (web build via Playwright or the iOS simulator via `simctl recordVideo`) → ffmpeg.

## Metadata limits
Name 30 · Subtitle 30 · Promotional text 170 · Description 4000 · Keywords 100 **bytes** · What's New 4000 ·
Review notes 4000. Support URL + Privacy Policy URL required; Marketing URL optional.
